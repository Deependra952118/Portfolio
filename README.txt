Deependra Singh - Portfolio
===========================
Open index.html in any browser. No build step needed.

Notes
- Put your resume next to index.html and name it: Deependra_Singh_Resume.pdf
  (the "Download resume" button points to that file).
- The AI voice guide uses the browser's built-in speech synthesis. It speaks
  when a visitor taps a navigation link. Use the "AI voice" button (bottom-left)
  to mute it. Edit the GUIDE object in the script to change the wording.
- Deploy free on GitHub Pages, Netlify or Vercel by uploading this folder.
